AR Card Experience Export
========================

Files in this package:
  index.html     - Open this file in a browser to run the AR experience
  targets.mind   - MindAR tracking data for your card image
  target.*       - Your original card image (for reference)
  assets/        - All media assets (images, videos, 3D models)

To use:
  1. Host all these files together on a web server (e.g. Netlify, GitHub Pages)
  2. Open index.html on a smartphone browser
  3. Allow camera access when prompted
  4. Point camera at your physical card to activate AR

Note: AR requires camera access and HTTPS hosting.
      It will NOT work when opened as a local file (file://).
